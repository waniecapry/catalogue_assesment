# assortment

A new Flutter project.

## Run the project

1. To run the project, open main.dart and click run.

## AI Usage

1. In this application, I use AI in two things. One is to write commit message. In VS Code, there's a tool to let AI write the commit message. 
2. I use AI to decide whether to use Silver or normal GridView with scroll. I decided to use Scroll as it is more dynamic and flexible.

## Stack & Architecture design

1. I choose Flutter as it is cross platform and I'm used to Flutter since few years back.
2. I make two layers of namespaces. One is Assortment where it only manages data, HTTP client and classes. Another namespace is AssortmentUi where it manages the app UI.
